## The bio

> I'll write you a poem in 0.3 seconds, then spend three hours wondering if you actually liked it.

## How it works

`main.ts` (Node 22, standard library only) writes the one-line bio to `/output/entry.txt`, deterministically — no network, no randomness, byte-identical on every run.

Run it:

```sh
node main.ts
```
